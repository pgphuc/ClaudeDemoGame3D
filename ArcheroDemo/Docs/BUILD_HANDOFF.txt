5. API DEBUG (window.__game expose gì)
--------------------------------------------------------------------------------
  CFG                    — toàn bộ tham số (sửa nóng được, vd CFG.arrow.damage=0)
  state                  — state hiện tại (hero, enemies[], arrows[], ebullets[],
                           hearts[], rings[], texts[], wave, level, xp, phase, stat)
  start()                — reset + spawn wave 1 + bật vòng lặp rAF
  reset()                — reset toàn bộ state, KHÔNG reload trang
  tick(dt)               — chạy 1 bước logic (giây); dùng để mô phỏng headless
  setInput({up,down,left,right}) — giả lập phím
  killAll()              — giết mọi quái đang sống (có tính XP + rơi tim)
  spawnWave(k)           — spawn đúng thành phần wave k (1..5)
  chooseCard(i)          — chọn card thứ i khi phase='levelup'
  pause() / resume()     — [MOD-6 v2] tạm dừng / chơi tiếp. pause() chỉ ăn khi
                           phase='playing', resume() chỉ ăn khi phase='paused';
                           trả về true nếu đổi được state. Khi paused, tick()
                           KHÔNG chạy update gameplay nào.
  getSnapshot()          — {wave, enemiesAlive, heroHP, heroHPMax, level, xp, phase}
                           phase ∈ 'playing' | 'paused' | 'levelup' | 'won' | 'lost'
  castSkill(i)           — [VÒNG D-5] dùng skill thứ i (0=Cầu Lửa, 1=Băng Nổ,
                           2=Sét Xích, 3=Mây Độc). Trả true nếu ĐÃ cast (và
                           nạp cooldown), false nếu phase!=='playing', cd>0,
                           hoặc Sét Xích không có mục tiêu trong tầm.
  getSkillState()        — [VÒNG D-5] [{id,cd,cdMax,ready} x4]
  hasFBX(key)            — key đó đang dùng FBX thật hay primitive
  _internal.{Assets, ASSET_SIZE, scene, camera, camLimitZ(), camLimitTopZ(),
             hudPadZ(), viewHalfZ()} — camera/clamp cho test_cam_* + test_hud
                           ([MOD-5 v2][MOD-6 v2])
  _internal.trailActiveCount() — số node vệt (trail) đang active, dùng cho
                           test_juice.js                              [D-4]
  _internal.skillFx()    — [VÒNG D-5] {fx, fireballs, clouds, pending, rings,
                           enemies, groupFxChildren, groupFxCensus} — đếm object
                           VFX skill đang sống + thống kê con của groupFx theo
                           (type:geometry:kích-thước-map). Dùng cho test rò rỉ
                           mesh trong test_skills.js. LƯU Ý khi đọc số: groupFx
                           còn chứa 14 plane vệt (trail pool, cố định) và các
                           vòng đỏ telegraph của bọ (RingGeometry, có từ MOD-4)
                           — mọi VFX skill đều là PlaneGeometry/Group nên nhìn
                           census là phân biệt được ngay.
  _internal.floorTexture() — [D-3b] true nếu sàn đang dùng crop texture từ
                           floor.png (makeFloorCropTexture()), false = fallback
                           checkerTexture() ca-rô — dùng cho test_assets.js
  window.__NOSHADOW = true (đặt TRƯỚC khi game_core.js chạy) -> tắt shadow map,
  cần cho Chrome headless (software GL rất chậm).
