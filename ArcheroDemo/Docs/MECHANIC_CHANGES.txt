D. RÀNG BUỘC KỸ THUẬT BẮT BUỘC (constraint — Agent C phải tuân)
--------------------------------------------------------------------------------
- Asset FBX do user export từ Unity (FBX Exporter), đặt trong
  D:/Project/ClaudeDemoGame3D/ArcheroDemo/Assets/; danh sách file FBX ghi
  trong assets_fbx.js. Agent C phải code lớp AssetLoader TÁCH RIÊNG: khi
  FBX tương ứng chưa có thì dùng primitive three.js (capsule/box/sphere
  màu thuần) cùng kích thước để thay thế tạm; khi FBX đã có thì swap vào
  mà KHÔNG đổi game logic. KHÔNG tự vẽ mesh phức tạp thay cho FBX.
- KHÔNG convert GLB, KHÔNG dùng Python; FBXLoader nạp trực tiếp trong browser.
- three.js r136 bản GLOBAL (không ES module) để đóng gói 1 file HTML.
- Sản phẩm cuối: 1 file .html self-contained, mở bằng double-click.
- Input di chuyển đọc từ bàn phím (keydown/keyup: WASD + phím mũi tên),
  KHÔNG dựng UI joystick ảo/touch cho di chuyển.
